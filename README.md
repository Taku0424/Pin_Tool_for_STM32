# STM32 Pin Labeler for KiCad

KiCadでコピーしたSTM32と周辺回路へ、ブラウザ上でGPIOラベルを追加・変更する静的Webアプリです。回路データはサーバーへ送信せず、ブラウザ内だけで処理します。

## 使い方

1. KiCadの回路図エディターで、STM32シンボル1個と必要な周辺回路を選択してコピーします。
2. Webアプリ右側の「KiCad回路」タブで「クリップボードから読み込む」を押します。自動で読み込めない場合は、手動欄へ貼り付けて「貼り付け内容を読み込む」を押します。
3. パッケージ図でピンを選び、使用する機能を設定します。
4. 右側の「ラベル設定」タブでラベル名と電気タイプを確認・編集します。
5. 左側の「KiCadへコピー」を押し、KiCadで `Ctrl+V` します。変換とクリップボードへのコピーは一度に行われます。

クリップボードの自動読み取りが許可されない場合でも、手動貼り付け欄を選んで `Ctrl+V` できます。自動コピーが許可されない場合は「KiCad回路」タブの手動コピー欄が開くので、`Ctrl+C` でコピーできます。

## 動作方針

- KiCadのシンボルライブラリは自動検出しません。
- 貼り付けた回路は一回限り使用し、ブラウザ内へ永続保存しません。
- 既存回路の部品、配線、配置、UUID、設定していないピンは維持します。
- 設定済みGPIOのネットに既存ラベルがあれば、同じ元ラベル名をまとめて変更します。
- ラベルがなければ、ピン端点へグローバルラベルまたは階層ラベルを追加します。
- VDD、GND、NRST、BOOTなどの保護対象ラベルは変更しません。
- 抵抗やコンデンサなどの部品を越えて接続をたどりません。
- 競合があるネットは変更せず、画面へ理由を表示します。

## CSV

3列、4列、5列の設定CSVを読み込めます。

```csv
mcu,pin,function,label,electrical_type
STM32F446RETx,PA9,USART1_TX,DEBUG_TX,output
STM32F446RETx,PA10,USART1_RX,DEBUG_RX,input
```

保存操作は常に5列CSVの新規ダウンロードです。同じファイルをブラウザから自動更新しません。

## 対応範囲

現在のラベル生成形式は、デスクトップ版と同じKiCad 9形式を基準にしています。既存ラベル名の変更は元データを維持するため比較的バージョンに依存しませんが、KiCad 8・10は実際のコピー内容を使った検証後に正式対応します。

## データ

STM32のピン情報は `data/*.csv` から読み込みます。`index.html` を直接開いた場合にも動作するよう、同じ内容を `data/embedded-csv.js` に同梱しています。

Web用CSVを更新した後は `npm run sync-data` で埋め込みデータを同期します。

## テスト

追加パッケージなしで、KiCad回路変換とCSV互換のテストを `npm test` から実行できます。
