# Pin Tool for STM32

STM32 のピン配置とピン機能を確認するための静的 Web アプリです
サーバーサイド処理は使わず、ブラウザ上だけで動作します

## 使い方

1. 左側の `MCU` から対象の STM32 を選択します

2. `Search` に機能名やキーワードを入力します
   ピンの機能の名前から番号を抜いたもので検索できます
   例: `USART_Rx`, `I2C_SDA`, `SPI`, `TIM_CH`, `ADC`, `GPIO`

3. パッケージ図上でピンをクリックすると、右側にそのピンで利用できる機能一覧が表示されます

4. 機能名をクリックすると、そのピンに機能を設定できます
   設定済みの機能はパッケージ図上にも表示されます

5. `Save CSV` で現在のピン割り当てをCSVとして保存できます
   `Open CSV` で保存済みのCSVを読み込めます

## データについて

このアプリは `data/*.csv` のピンデータを読み込んで動作します
ブラウザで `index.html` を直接開く場合にも動作するよう、同じ内容を
`data/embedded-csv.js` に同梱しています。CSVを更新した場合は、このファイルも同期してください
